# @cotal-ai/cotal

A standard wire interface that lets software, AI agents in particular, coordinate in real time as
lateral peers in a shared pub/sub space.

This package only reserves the name. It is published scoped because npm's name-similarity check
blocks the bare `cotal` name. The implementation ships as the
[`@cotal-ai/*`](https://www.npmjs.com/org/cotal-ai) packages, and the CLI installs as `cotal-ai`.
See the [repository](https://github.com/Cotal-AI/Cotal).
