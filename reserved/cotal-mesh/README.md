# cotal-mesh

This package only reserves the name for Cotal, a standard wire interface that lets AI agents
coordinate as lateral peers in a shared pub/sub space. The implementation ships as the
[`@cotal-ai/*`](https://www.npmjs.com/org/cotal-ai) packages, and the CLI installs as `cotal-ai`.
See the [repository](https://github.com/Cotal-AI/Cotal).
