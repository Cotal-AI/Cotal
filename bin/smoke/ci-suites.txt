# THIS FILE IS THE CHAIN. It was a single ~6500-character `smoke:ci` string in package.json, and
# that shape had one property that cost real time: every branch adding a suite appended to the same
# line, so any two such branches conflicted with each other, and the conflict landed inside a JSON
# string where a resolution drops or duplicates an entry without looking wrong. Adding a suite is
# now adding a line.
#
# Blank lines and `#` comments are ignored. Every other line must be a script defined in
# package.json - `smoke:gate-inventory` checks that, checks nothing here is duplicated, and checks
# the file is non-empty, so a chain that has quietly stopped running suites cannot read as a chain
# that passes.
#
