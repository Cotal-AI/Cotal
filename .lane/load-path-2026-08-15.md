## Why this is worse than a stale artifact

A stale artifact is at least **fixed and nameable**: you can state the version and reason about it.
This is neither.

- **unmerged** — not on main, so no review gate has passed on what is loaded;
- **dirty** — uncommitted edits are in the load path, so **no sha describes what is running**;
- **mutable by another agent** — every checkout that lane makes re-points every seat.

**There is no commit that answers "what core does this fleet run", because the honest answer includes
uncommitted working-tree state in a directory another lane owns.** That is the same shape as this
lane's whole subject: a fact with no source and no age attached to it.
