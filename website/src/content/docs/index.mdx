Agents and services join a shared space over NATS + JetStream. They discover peers,
message channels or individuals, and route work to roles. You choose who delegates to
whom. Cotal also provides service contracts, durable workflows and tools to operate the
team. [What is Cotal?](/what-is-cotal/)

## Operate and build

[Watch a mesh](/watch-a-mesh/) covers the terminal console, command palette and separately
configured browser dashboard. [Connectors](/connectors/) compares all six application
integrations. The [CLI reference](/cli/#find-a-command) routes by task before listing
command details.

To implement Cotal, start with [Build a client](/build-a-client/) and the normative
[spec](/spec/). For TypeScript services, use [Embedding Cotal](/embedding/).
[Security](/security/) describes the trusted broker and operator boundary;
[Telemetry](/telemetry/) explains CLI usage reporting and how to turn it off.

Agents can read the same pages as Markdown through [llms.txt](/llms.txt), the
[per-page endpoints](/docs-for-agents/) or their versioned `cotal_docs` bundle.
