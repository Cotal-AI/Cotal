Add the design record for `once`, an at-most-once scope for cotal-lang steps that write to a far side, in `docs/design/at-most-once-external-effect.md`. A resume that finds a step inside `once` begun and never settled does not dispatch it again: it opens a hold, an ordinary checkpoint minted under a hold id derived from the step's recorded request id, and the settler's value becomes the step's result, while an expired hold fails the step with the catchable L4027. A hold the host refuses leaves the step pending rather than refused, so no later host writes again. Only `ask` runs inside `once`: a `checkpoint`, a `waitUntil` and a `conclave` call a handler more than once at one key, a `spawn`, a `turn`, a `monitor` and a `notify` build run state inside their handler that a settled answer cannot, and a `sleep` and a `wait` write nothing to bound while holding a pause or a durable consumer only their own ending ends, so each is refused before it begins (L4028). The hosted runtime ends the pause the held `ask` armed before the hold opens, and answering, amending and printing a held step all read the hold's pause, so the seat the attempt was relayed to settles the step only through the hold. A settled `once` replays without entering its body, so the body returns its result and a write from it to a binding outside it is refused (L2032). The record fixes the surface, the journal's new `hold` field, the hosted runtime's pause authority, adoption, discharge and answer path for a hold, a fork inside `once`, the insertion-only normative text, including `once` in every closed list of scopes and entry kinds, and the acceptance runs. `once` becomes a reserved name, so a program that declares its own `once` binding is refused (L2002). No package behavior changes in this revision.
