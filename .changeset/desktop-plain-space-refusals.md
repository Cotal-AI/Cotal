The desktop app no longer shows the background service's raw refusal in a space row. A row such as "The local space connection is held by https://…" now says "This space is set up under another sign-in on this computer." and each refused row has one button for its cause instead of only Remove. Details no longer shows command lines or web addresses, and a hosted Manager's reason in `cotal daemon status` names what happened while the command stays in its next step.
