Your Cotal account can now ask a computer to run Repair. The background service reads a repair request from the account, checks the computer and answers in its next heartbeat with what it found, then runs that plan when the account asks with the same check. From the account it runs only the safe fixes: finding agent apps, starting stopped spaces and removing an old registration. Moving or starting the service still needs you at the computer, and reset never runs from the account. Each request runs once, including after a restart. A newer request replaces one that is waiting, and the answer never carries a file path, a command, or your account, computer or space names.
