Report an operator address that closes a sentence. The operator literal gate read a trailing dot as part of the candidate, so an address written as the last word before a full stop was silent in both the IPv4 and the IPv6 class, in prose and in comments. A trailing dot is now admitted before closing quotes, brackets and sentence punctuation followed by whitespace or the end of the line. It is still refused before a path, label or digit, so a name carrying further labels is not cut into. The counted fixture allowlist gains one occurrence for a range boundary constant that closes a sentence in a comment.
