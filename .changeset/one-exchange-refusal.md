Every refused exchange that spends a face's refusal budget answers through one helper. The helper records the failure, writes the audit line, and answers 429 with the mask when the peer is already throttled, or else the route's own status. The routes covered are the exchange body and view refusals, the agent and human exchange catches, chat sessions, the manager instance list, the service endpoint host and manager-service authority. Before, each route spelled the sequence itself. Behavior is unchanged.
