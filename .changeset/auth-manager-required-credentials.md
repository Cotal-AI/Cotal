The manager-service authority issuer reads the credentials each operation must carry from one table keyed by the core operation type. It used a nested ternary whose last arm fell back to the five standing credentials, so an operation added to the core list compiled here unchanged and was refused at runtime as `did not issue required credential supervisor`. Such an operation now fails to compile until it has an entry. The eight current operations issue and refuse as before.
