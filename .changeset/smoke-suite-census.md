`pnpm smoke:gate-inventory` now reads the entry file of every suite the gate reaches and accepts only failure shapes it can follow to the exit status, following calls through the file's own functions, aliases and methods. It refuses a `finally` exit that can turn a throw into exit 0 unless the first statement of a catch arm fails through that exit. It refuses a suite whose expected cell count is not compared by `===` or `!==`, as the whole condition of a statement every run that passes reaches, with no catch or rejection handler able to skip it, with a mismatch that exits with a status from 1 to 255, sets such an exit code nothing overrides, or throws uncaught, unless the suite is listed in `bin/smoke/unpinned-suites.txt`, the existing debt, which a digest in the gate binds to its entries. A reached suite whose entry file cannot be read is refused unless it is listed with a reason.
