`pnpm smoke:gate-inventory` now reads the entry file of every suite the gate reaches and accepts only failure shapes it can follow to the exit status, following calls, `new` and tagged templates through the file's own functions, classes, aliases, methods and returned functions. It refuses a `finally` exit that can turn a throw into exit 0 unless the first statement of a catch arm fails through that exit. It refuses a suite whose expected cell count is not compared by `===` or `!==` with the counters of the cells that ran, read in the comparison itself, as the whole condition of a statement every run that passes reaches, with no catch or rejection handler, unawaited async call, argument or callback able to skip it, with a mismatch that exits with a status from 1 to 255, sets such an exit code nothing overrides, or throws uncaught, unless the suite is listed in `bin/smoke/unpinned-suites.txt`, the existing debt, which a digest in the gate binds to its entries. A reached suite whose entry file cannot be read is refused unless it is listed with a reason.
