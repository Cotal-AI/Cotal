A project's own `.cotal` can now declare MCP servers, `spawn.env` names and persona launch options only in a folder you trust, and the new `cotal trust <path>` command trusts one. A spawn that reads any of them from another folder refuses, names the file, the entries, the folder and that command, and launches nothing, both in this terminal and through a manager. The config file's other fields still apply, and a persona file outside any project, `--opt` on the command line and a manifest's own `launchOptions` are not affected. A persona file a manifest names for `cotal up -f` or `cotal team deploy` follows the same rule, refused while the manifest resolves and again by the manager that launches or resumes it. A persona file is judged by the path given and by the file that path reaches through symbolic links, so a link to a persona under a folder that is not trusted is refused wherever the link is. A project config whose file or `.cotal` folder belongs to another account is refused. `cotal setup`, `cotal space create` and `cotal up` trust a folder only when they made its `.cotal` in that run; a folder that arrived with one, such as a cloned repository, is trusted only by `cotal trust`. The first command at this version writes `trusted-projects.json` in the operator config folder once, trusting every root a space was registered or prepared at before it, so those projects keep working. `trusted-projects-seed.json` in the Cotal home records that this ran, so removing the trusted projects file, or using another config folder with the same Cotal home, never seeds again. Removing `trusted-projects-seed.json` runs the seed again on the next command, from the spaces registered at that time. A seed record that cannot be read warns on each command, says how to clear it, and blocks nothing. Trust follows the stored path. A trusted projects file another account owns or may write trusts nothing. `loadCotalConfig` in `@cotal-ai/core` now takes a second argument that answers whether a project folder is trusted; `@cotal-ai/workspace` exports `isTrustedProject`, `trustProject`, `seedTrustedProjects`, `personaLaunchOptionsRefusal` and `manifestPersonaLaunchOptionsRefusal`.
