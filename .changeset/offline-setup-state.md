A computer that is already set up no longer returns to the four setup steps when the network is down or a status read fails. The window, the header pill and the tray say "No internet connection" or "Can't reach your space", the connection comes back by itself, and setup does not run while the computer is known to be offline. When the background service was set up by another Cotal installation, Details says so without a command line.
