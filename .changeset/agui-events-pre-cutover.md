Key the per-agent event channel on the agent's principal and add the durable event-emitter foundations.

The persisted resume document moves to **version 2**. `launch.transcript` becomes `launch.events`, migrated at read time — a v1 document still resumes, and both polarities are preserved, so an agent preserved with the flag off comes back with it off. A document written by a newer build is refused with an operator-facing error naming the version and the remedy, rather than being partially read.

`multicastExpecting` gains a serialized-append fence proven across the whole expectation space, not only the first publish onto an empty subject. `JsonlFileSource` states the real bound of its consumed-prefix seal (the last 512 bytes, not the whole prefix) and refuses a symlinked source. `EventWal` lands as the emitter's durable state machine: publish never precedes the write-ahead record, success becomes durable before the frontier moves, and every corrupt, zero-byte or mixed-vintage document fails loud rather than being repaired.

Resuming an events-enabled agent now refuses when its preserved publish grant does not include the event channel, instead of launching it with a mute stream.

The write-ahead record now carries the frame's **body**, so a restart holding an unacknowledged frame can re-publish the same one — previously it recovered the id and the expectation that name a frame and nothing to send. `EventWal` also verifies the **space** it was opened under, alongside the principal and thread it already checked, and refuses two documents it used to accept: a nonzero frontier missing the source position it was derived from, and a `pending` key that is absent rather than explicitly null. Both were silent-loss paths — an absent cursor does not resume the durable source, it adopts at its current end.

The per-agent event channel is now keyed on the agent's **principal** — `events.<owner>.<actor>` — instead of its display name. A display name is a client-side handle, not an identity: it is case-folded and separator-collapsed on its way to a subject, so distinct agents fused onto one channel and, because the publish grant is minted from that value, onto one grant. The mapping is now injective, and the sanitiser and truncated digest that defended the old one are gone with it. `Connector.eventChannel` takes the principal, both grant paths derive it after the identity is minted rather than before, and each connector publishes to the channel of the principal its endpoint authenticates as. `--events` now requires an authed mesh: an open-mode session self-mints a new actor per process, so it is refused with a message naming what is missing rather than falling back to the name.

A publish grant naming an event channel it can never match is now refused **by name, at grant time** — at foreground spawn, at manager spawn, and on resume from a preserved cut — rather than launching an agent whose stream is silently mute. The principal key costs one token more than the flat name-keyed form it replaced, so an inherited `events.*` (or a bare `events.<sanitised-name>`) matches nothing, and at the broker a grant that matches nothing is indistinguishable from a channel with no traffic. The error names the offending pattern and the shapes that do work: `events.<owner>.>` for every actor of one owner, `events.<owner>.<actor>` for one agent. Grants outside the event namespace are untouched, and the check runs whether or not the launch also asked for `--events`, because a mute grant is mute either way.

The AG-UI event vocabulary lands as `connector-core/src/agui.ts`: the mapped event subset, their constructors, the frame envelope, and an incremental bracketing checker. The vocabulary is adopted; the SDK is not — `@ag-ui/core` is a `devDependency` pinned exact, imported for types only, so no zod copy reaches a bundled connector.

The event emitter lands in the same module and ties those pieces to the durable ones. It reads a durable source forward from the write-ahead log's cursor, maps records to events, packs them into frames that provably fit, and appends each under an optimistic-concurrency expectation with a frozen dedup id. A duplicate acknowledgement halts it rather than being folded as success — on a first attempt that means a body it did not write holds its id, and on a retry it means the stream is not the single-replica configuration the design requires; either way, folding would advance the frontier and the source position past events that were never published. A transport error is deliberately not a halt: it leaves the frame recorded and unacknowledged, which is the state that means "we do not know", and the next start re-publishes the same one. The replication-factor preflight now runs at that start, before anything — including a recovery re-publish — can reach the wire.

A durable source now returns a cursor **per record**, not one for the whole read. A frame may cover only part of a batch, and it has to record a position that means exactly "every record in this frame is consumed"; with a single end-of-batch cursor, folding such a frame would skip the records the later frames were carrying, with no gap for a reader to notice. Frames are therefore packed at record boundaries and a single record too large for one frame is refused rather than truncated.

A frame that cannot be bracketed after a restart now says so. The write-ahead log persists the stream's position and the frame in flight, not the set of open runs and messages, so a process that stops mid-run resumes at events whose opening was already published and refuses the first of them. That refusal now identifies itself as lost writer state rather than presenting as a protocol violation by the agent, which is a different problem with a different fix.

The browser dashboard can now **display** a frame. A frame carries no text part by design, so every surface that renders parts showed it as a marker naming a kind it could not draw — correct, and not a transcript. `parts.js` now consults a per-kind renderer registry before its fallbacks, and a new served file registers an `ag-ui.frame` renderer into it, so the dispatcher still knows nothing about AG-UI and an absent registration degrades to the same named marker as before. A renderer that throws or returns a non-string is reported by name rather than blanking the body — the failure the dispatcher exists to remove, which the extension seam would otherwise have reintroduced.

The browser cannot import from `@cotal-ai/core`, so that renderer is a second implementation of one already in `connector-core`, and the duplication is held closed by test rather than by intention: a parity suite in the composition root drives both over a shared corpus and requires byte-identical output, reporting only digests and positions on a mismatch so that pointing it at real input later is not also a decision to start printing it. Its corpus coverage is measured against the emitter's own enumerable event types and printed on every run, so a new event type shows up as uncovered the day it lands. That suite already found two divergences: accumulators keyed by plain object reordered integer-like message ids and dropped a `__proto__`-keyed stream outright, and the browser told a non-frame part it was a frame carrying no events.

**The AG-UI frame's wire identity and its renderer move into `@cotal-ai/core`.** `AGUI_FRAME_KIND`, `AGUI_EVENT_TYPE` and `isAguiFramePart` now live in core and are re-exported from `@cotal-ai/connector-core`, so existing importers are unaffected; the emitter, the event constructors, the frame envelope and all zod validation stay in the connector. The test for an adapter concept is not where the code was written but whether one adapter could change it while the others are unaffected, and `ag-ui.frame` fails that test in the direction that matters: every connector emits it, it travels on the wire, and no adapter may redefine it alone. Its previous home was an artifact of where the emitter was built.

The consequence is that `cotal console`, `cotal join` and `examples/02` display a frame with **no change to `implementations/cli`** — core's `partsToText` already resolved renderers from the registry, and the only missing piece was that nothing shipped performed the registration. Core now performs it on import. The alternatives were rejected on cost: a static import in the composition root would have retired the documented invariant that nothing static-imports connectors on the published binary, and a `requiredExtensions` declaration would have forced the viewing commands to name a connector they cannot know, so a mesh of OpenCode agents would render nothing while the declaration looked satisfied.

Core gains no dependency on `@ag-ui/core` and cannot: the package is unresolvable from `packages/core`, so a type-only import would fail the build rather than ship silently. The hand-written event literals are still checked against the real enum by the conformance smoke, which stays in the connector where that package is available.

Nothing emits yet; the connectors are untouched and still publish their existing mirrors.
