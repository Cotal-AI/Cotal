Specify a portable bootstrap for an already-enrolled managed agent in SPEC §13.16, the embedding guide and a design record. A manager that enrolled an agent through `enrollManagedAgent` would hand its child one closed `cotal-managed-handoff/v1` document by value through an optional `Runtime.spawnDelegated` method, so a child in a sandbox, container or other host can start without the manager's filesystem. The document carries the issued owner, actor, host-chosen lifecycle UID, sentinel, pinned exchange base and the raw actor token, which the host never receives. The child removes that file before any other check, runs the existing enrollment-redeem consumer from it, refuses a mismatched owner, actor or lifecycle UID before any plane opens, never enrolls or mints, and exchanges through `agent-bearer --exchange-url` unchanged. The manager refuses `--resume`, `--cwd` and shared MCP servers for such a seat before enrolling. Readiness stays presence-observed, a lost create acknowledgement stays held as uncertain and is never retried, a provider's answer that no resource exists is not an exit, and the close by the lifecycle-derived key is fenced against a create that could still land. Retirement reuses prepare-retirement, the known runtime handle's fenced close and the terminal barrier, including after the manager is gone. This is a contract change only. No runtime method, handoff reader or CLI input ships yet.
