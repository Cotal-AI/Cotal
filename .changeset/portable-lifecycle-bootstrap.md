Specify a portable bootstrap for an already-enrolled managed agent in SPEC §13.16, the embedding guide and a design record. A manager that enrolled an agent through `enrollManagedAgent` would hand its child one closed `cotal-managed-handoff/v1` document by value through an optional `Runtime.spawnDelegated` method, so a child in a sandbox, container or other host can start without the manager's filesystem. The document carries the issued owner, actor, host-chosen lifecycle UID, sentinel, pinned exchange base and the raw actor token, which the host never receives. The child runs the existing enrollment-redeem consumer from that file, refuses a mismatched owner, actor or lifecycle UID before any plane opens, never enrolls or mints, and exchanges through `agent-bearer --exchange-url` unchanged. Readiness stays presence-observed, a lost create acknowledgement stays held as uncertain and is never retried, and retirement reuses prepare-retirement, the known runtime handle's closure and the terminal barrier, including after the manager is gone. This is a contract change only. No runtime method, handoff reader or CLI input ships yet.
