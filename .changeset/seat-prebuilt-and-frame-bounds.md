Ship the Linux SO_PEERCRED helper as a prebuilt binary instead of compiling it on every customer install. Source builds compile against the Node headers next to the running binary, not a hardcoded `/usr/include/node`, and there is no `binding.gyp` for install to infer `node-gyp rebuild` from. Bound length-prefixed frames by claimed size at the header and by residual after draining complete frames, with an 8 MiB body cap so a 1000-row coloured snapshot still encodes.
