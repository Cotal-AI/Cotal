# Desktop release acceptance on lab machines

Run this continuation only on a disposable lab machine assigned for desktop acceptance. Do not run it on a hosted GitHub runner. Use the assigned account and its existing space. This part requires the coordinator's account approval and a supported agent application with working authentication. Do not put a model key into the installer, script or test output.

1. With `DESKTOP_LAB_DISPOSABLE=1` in the lab session, run `clean-install-lab-linux.sh`, `clean-install-lab-macos.sh` or `clean-install-lab-windows.ps1` with the absolute installer path. Open the installed app if the script does not open it. For an upgrade run, keep the installer and state from the older app on the same machine. Do not import connector state from another machine.
2. Select **Continue with Cotal Cloud**. Observe the background service starts and the approval screen appears. Pause here. Read the code directly from the app. Send it only to the designated approver by direct message as `approve <code>`. Never capture the approval window or put the code, approval link, account name or credentials in files, shell commands, workflow output or channel messages. Wait up to four minutes for approval. If it expires, ask the app for a new code and try once more. Record only whether approval succeeded.
3. Select **Open dashboard**, and have the approver enable the assigned space for this computer if required. Otherwise select the assigned space in the app and choose **Connect this computer**. When the app shows **Connected**, report whether the assigned space shows an answering Manager. If it refuses, record the first failing step and the displayed reason after removing names, addresses and secrets.
4. If needed, open **Agent apps** and use the app's installer and sign-in for the approved harness. Use the assigned authentication outside this script. From the space's dashboard, start one agent with the current approved model for that harness. Require both a reply from the agent and a running agent row in the desktop window. Stop the agent, disconnect and sign out through the product. Let the approver remove the lab computer from the account.

Report numbered pass or fail outcomes, stopping at the first refusal. A device code issued, an app launched or a dashboard row present does not prove a Manager or agent has answered. The hosted workflow covers the account-independent part against a disposable local space. A successful hosted check does not count as this lab continuation.
