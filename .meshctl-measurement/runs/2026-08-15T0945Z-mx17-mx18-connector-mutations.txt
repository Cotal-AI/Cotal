## WHY THERE ARE TWO MUTATIONS
One mutation proves the ASSERTION arm. The control arm is the half that was missing everywhere on
this box tonight, and a control that cannot be shown to fail is not a control. So: remove the guard
(the assertion arm must redden) and make the guard unconditional (the control arm must redden).

## THE MECHANISM THAT MADE IT POSSIBLE
--private-src: copy extensions/connector-core/src to a scratch INSIDE the package, mutate the COPY,
redirect by RESOLVED URL via a prefix map. The tree is never written. Needed because the suite
imports its subject as `../src/agent.js` — relative source, compiled in memory by tsx — which a
bare-specifier redirect cannot reach. LIMITS-private-build.md #2 had a sibling in the suite this
branch had been calling its most-graded.

SUBJECT-SIDE GATE, two arms, both driven BEFORE either was cited:
  with the hook     subject -> .privsrc-*/src/agent.ts   IN-MAP yes  OUT-OF-MAP untouched  rc=0
  without the hook  subject -> extensions/.../src/agent.ts                                 rc=1
The out-of-map arm resolves a DIFFERENT package's source and requires it NOT be rewritten. Without
it a hook that redirected the entire module graph would pass the first arm.
