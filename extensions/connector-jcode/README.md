# @cotal-ai/connector-jcode

The Jcode adapter: a host-mode peer driven through Jcode's Harness API bridge. A thin client over
[`@cotal-ai/connector-core`](../connector-core).

**Tier:** `extensions/`. Peer-depends [`@cotal-ai/core`](../../packages/core); self-registers on
import.

See [docs/connect-jcode.mdx](../../docs/connect-jcode.mdx) for the integration guide, and the
[root AGENTS.md](../../AGENTS.md) for the tier rules.
